# Telecomunicaciones: retención y dashboard

## Objetivo

Analizar factores asociados a la pérdida de clientes y crear una vista ejecutiva para monitorear indicadores de retención.

## Entregable analítico

Dashboard en Power BI con indicadores de clientes, bajas, tasa de churn y cortes de análisis por variables de negocio. El archivo de Power BI se conserva fuera del repositorio; aquí se documenta el enfoque para mantener el portafolio ligero y reproducible.

## Tecnologías

Power BI, DAX y Excel.
