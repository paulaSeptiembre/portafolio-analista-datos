# Retención de clientes de una startup tecnológica

## Objetivo

Analizar patrones de retención por mes y trimestre para identificar cohortes con mayor riesgo de abandono y orientar acciones de producto o comunicación.

## Enfoque

1. Consolidar actividad y fecha de alta por cliente.
2. Calcular cohortes mensuales y tasas de retención.
3. Comparar permanencia por periodo y detectar caídas relevantes.
4. Comunicar hallazgos mediante tablas y visualizaciones de cohortes.

## Tecnologías

BigQuery, SQL y archivos CSV de práctica.
