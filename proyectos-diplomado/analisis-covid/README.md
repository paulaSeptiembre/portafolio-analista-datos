# Análisis exploratorio de COVID-19

## Objetivo

Explorar tendencias temporales y geográficas en datos de práctica para comunicar cambios en casos, recuperaciones o indicadores sanitarios.

## Competencias demostradas

- Limpieza y normalización de fechas.
- Agregación de métricas por periodo y ubicación.
- Validación de consistencia antes de visualizar.
- Comunicación de tendencias evitando interpretar correlación como causalidad.

## Tecnologías

SQL en BigQuery y visualización de datos.
