# Casos de análisis del diplomado

Colección de casos académicos desarrollados durante el certificado de análisis de datos de Laboratoria e IBM. Los datos fuente se mantienen fuera del repositorio; los ejemplos usan tablas de referencia y consultas reproducibles para mostrar el enfoque analítico.

## Casos incluidos

| Caso | Pregunta de negocio | Herramientas |
|---|---|---|
| [Retención de startup tecnológica](retencion-startup/README.md) | ¿Qué patrones de uso y permanencia ayudan a anticipar la pérdida de clientes? | BigQuery, SQL, CSV |
| [Segmentación de clientes e-commerce](segmentacion-ecommerce/README.md) | ¿Cómo agrupar clientes para priorizar campañas y mejorar la experiencia de compra? | BigQuery, SQL |
| [Análisis de COVID-19](analisis-covid/README.md) | ¿Cómo explorar tendencias temporales y geográficas en datos públicos? | BigQuery, SQL, visualización |
| [Telecomunicaciones: retención y dashboard](telecom-powerbi/README.md) | ¿Qué variables explican la pérdida de clientes y cómo monitorearlas en un dashboard? | Power BI, DAX, Excel |

## Criterio de publicación

- No se incluyen datos personales, credenciales ni archivos de fuentes privadas.
- Las consultas emplean nombres de tabla de ejemplo y deben conectarse a conjuntos de datos públicos o sintéticos.
- Los archivos `.pbix` y conjuntos de datos de origen no se versionan por tamaño y trazabilidad; la documentación describe el análisis realizado.
